# Project Atom
Atom é um projeto de estrutura de um novo ecossistema, ultilizando IA de assistente como motor de busca de Torrents com links magnéticos de diferentes conteúdos e análisa-los, com interface mais limpa e intuitiva. Nosso foco é desenvolver um novo ecossistema open-source, com efeito hydra.

## Objetivo
Nosso objetivo é preservar conteúdos (novos ou antigos), e facilitar a disponibilidade do mesmo. Não hospedamos os conteúdos, somos o meio que você precisa para encontra-los. Queremos tornar o sistema Torrent mais confiável e principalmente com boa qualidade.

## Contruibuição
Você pode criar uma replica, mandar sugestões ou ajudar a melhorar ainda mais essa ferramenta.
